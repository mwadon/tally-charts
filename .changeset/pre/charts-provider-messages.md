'tally-charts': minor

`ChartsProvider` takes a `messages` prop that translates the built-in text: "No data", "no value", the keyboard hint, the "n of total" position, target text, "Now" and "Total", the column headers of the hidden data tables (a header taken from a string accessor still keeps the field name), the RunwayChart status and legend, the Heatmap bin labels, the Delta direction words and the spoken rows of ComparisonBars and WaterfallChart. Strings use `{placeholders}`, and any key left out, or set to `undefined`, keeps its English default. A nested provider without `messages` inherits its parent's; one with `messages` replaces them, and any key it leaves out goes back to English. The `ChartMessages` type and a read-only `DEFAULT_MESSAGES` are exported; the keys and placeholder names are public, and new keys can arrive in a minor, so type a translation as `Partial<ChartMessages>`. A bundle holds only the English strings its own components can show. A per-chart prop such as `empty`, `keyboardHint`, `targetLabel`, `totalLabel` or `dataTable.columns` still wins. A test now fails when a new user-visible English literal appears in the React sources outside the defaults.
